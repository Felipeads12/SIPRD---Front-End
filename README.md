# SIPRD - Sistema Inteligente de Prevenção e Resposta a Desastres Naturais

## 📌 Sobre o Projeto

O SIPRD (Sistema Inteligente de Prevenção e Resposta a Desastres Naturais) é uma aplicação desenvolvida com o objetivo de auxiliar a população na prevenção, monitoramento e resposta a possíveis desastres naturais.

O sistema fornece informações relevantes sobre riscos ambientais, condições climáticas, alertas de eventos naturais e orientações de segurança para que os usuários possam agir de forma preventiva e segura diante de situações de emergência.

Além disso, o SIPRD permite o registro de ocorrências de desastres e disponibiliza contatos de emergência para facilitar o acesso rápido aos órgãos responsáveis.

## 🎯 Objetivo

Desenvolver uma solução tecnológica capaz de:

- Monitorar possíveis desastres naturais.
- Fornecer informações preventivas.
- Exibir alertas de riscos ambientais.
- Disponibilizar dicas de segurança.
- Permitir o registro de ocorrências.
- Facilitar o acesso a contatos de emergência.
