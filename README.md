# SIPRD - Sistema Inteligente de Prevenção e Resposta a Desastres Naturais

## 📌 Sobre o Projeto

O SIPRD (Sistema Inteligente de Prevenção e Resposta a Desastres Naturais) é uma aplicação desenvolvida com o objetivo de auxiliar a população na prevenção, monitoramento e resposta a possíveis desastres naturais.

O sistema fornece informações relevantes sobre riscos ambientais, condições climáticas, alertas de eventos naturais e orientações de segurança para que os usuários possam agir de forma preventiva e segura diante de situações de emergência.

Além disso, o SIPRD permite o registro de ocorrências de desastres e disponibiliza contatos de emergência para facilitar o acesso rápido aos órgãos responsáveis.

## 🎯 Objetivo

Desenvolver uma solução tecnológica capaz de:

- Monitorar possíveis desastres naturais.
- Fornecer informações preventivas.
- Exibir alertas de riscos ambientais.
- Disponibilizar dicas de segurança.
- Permitir o registro de ocorrências.
- Facilitar o acesso a contatos de emergência.
## 🚀 Funcionalidades

### 📍 Antecipação de Desastres

Permite consultar informações relacionadas a possíveis riscos ambientais em uma cidade informada pelo usuário.

### 🚨 Reportar Desastre

Usuários autenticados podem registrar ocorrências de desastres informando:

- Tipo do desastre
- Endereço
- Descrição
- Gravidade

Após o registro, o sistema gera um relatório da ocorrência.

### 🛡️ Dicas de Segurança

O sistema disponibiliza orientações específicas para:

- Enchentes
- Tempestades
- Deslizamentos
- Incêndios
- Queimadas
- Terremotos

As dicas são organizadas em:

- Antes do desastre
- Durante o desastre
- Depois do desastre

### 📞 Números de Emergência

Consulta rápida aos principais órgãos de emergência:

- Bombeiros (193)
- SAMU (192)
- Defesa Civil (199)
- Polícia Militar (190)

## 📚 Contexto do Problema

Os desastres naturais afetam milhares de pessoas todos os anos, causando impactos sociais, econômicos e ambientais.

Muitas vezes a população não possui acesso rápido a informações confiáveis ou orientações adequadas para lidar com essas situações.

O SIPRD foi desenvolvido para auxiliar na conscientização, prevenção e resposta a esses eventos, promovendo maior segurança e preparação da população.
